# Personagens — prompts prontos

Cada bloco abaixo já está completo (estilo + personagem + pose). É só copiar e colar no ChatGPT.

**Como usar:**

1. Gere a **ficha de referência** de cada personagem primeiro, anexando a arte-chave (`loft_keyart.png`).
2. Nas poses seguintes, anexe a **ficha de referência daquele personagem**.
3. Salve cada imagem com o nome indicado em `assets-src/shared/`.
4. Se não sair com fundo transparente, peça: *"same image with a solid flat magenta #FF00FF background"*.
